# 将 PowerPoint 幻灯片按内容尺寸裁切并拆分为 PDF

## 问题

一份 PowerPoint 的幻灯片画布尺寸统一，但每页图表、截图或文字实际占用的区域不同。直接导出 PDF 后，每页都沿用幻灯片的画布尺寸，内容较小的页面会留下大块空白。如何按每页的内容边界自动去掉白边，并把每一页保存为独立的 PDF？[Microsoft 支持：更改幻灯片大小](https://support.microsoft.com/en-us/powerpoint/change-the-size-of-your-powerpoint-slides)

## 解决方法

先用 PowerPoint 导出完整 PDF，再运行一个 Python 脚本。脚本用 `pdfCropMargins` 逐页检测内容边界，裁切后在四周各留约 2 毫米，再用 PyMuPDF 将每页写成一个 PDF。各页可以有不同的宽高，原 PDF 中的文字和矢量图保留为原有内容。[pdfCropMargins 文档](https://github.com/abarker/pdfCropMargins#python-interface) · [PyMuPDF 文档](https://pymupdf.readthedocs.io/en/latest/document.html#Document.insert_pdf)

### 1. 在 PowerPoint 中导出 PDF

在 Windows 版 PowerPoint 中，打开 **文件 → 导出 → 创建 PDF/XPS 文档 → 创建 PDF/XPS**。发布范围选择所有幻灯片，优化选项选择 **标准**。以下命令以导出的文件 `1.pdf` 为例。[Microsoft 支持：将 PowerPoint 保存为 PDF](https://support.microsoft.com/en-us/powerpoint/training/save-powerpoint-presentations-as-pdf-files)

### 2. 在 PowerShell 中安装依赖

打开 PowerShell。如果已经激活 Conda 环境，例如提示符前显示 `(base)`，直接用当前环境的 `python`。下面两行分别检查 Python 和安装依赖。已经安装 `pdfCropMargins` 的环境可以跳过安装。

```powershell
python --version
python -m pip install pdfCropMargins
```

`pdfCropMargins` 会一并安装 PyMuPDF。脚本通过 Python 导入并调用裁切函数，因此只需当前终端能运行 `python`。[pdfCropMargins 安装说明](https://github.com/abarker/pdfCropMargins#installing)

### 3. 保存 Python 脚本

将下面的代码保存为 `crop_split_pdf.py`，放到导出的 PDF 所在目录。

```python
"""Crop a PDF page by page and save each page as a separate PDF."""

import argparse
from pathlib import Path
from tempfile import TemporaryDirectory


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--file", required=True, type=Path, help="Input PDF path")
    args = parser.parse_args()
    source = args.file.expanduser().absolute()
    if not source.is_file() or source.suffix.lower() != ".pdf":
        parser.error(f"PDF file not found: {source}")

    output = source.with_name(f"{source.stem}_split")
    if output.exists():
        parser.error(f"Output folder already exists: {output}")

    try:
        import pymupdf
        from pdfCropMargins import crop
    except ImportError as exc:
        parser.exit(1, f"{exc}\nInstall with: python -m pip install pdfCropMargins\n")

    try:
        with TemporaryDirectory(prefix=".crop-split-", dir=source.parent) as work_dir:
            work = Path(work_dir)
            cropped = work / "cropped.pdf"
            pages = work / "pages"
            pages.mkdir()

            # Crop each page independently and leave six PDF points around its content.
            cropped_path, code, _, _ = crop([
                "-p", "0", "-a", "-6", "-o", str(cropped), str(source),
            ])
            if code not in (None, 0) or not cropped_path or not cropped.is_file():
                parser.exit(1, "PDF cropping failed. See the messages above.\n")

            with pymupdf.open(cropped) as document:
                count = document.page_count
                digits = max(3, len(str(count)))
                for index in range(count):
                    with pymupdf.open() as single_page:
                        single_page.insert_pdf(document, from_page=index, to_page=index)
                        single_page.save(pages / f"page-{index + 1:0{digits}d}.pdf")

            pages.rename(output)
    except (OSError, RuntimeError, ValueError) as exc:
        parser.exit(1, f"Could not crop and split the PDF: {exc}\n")

    print(f"Saved {count} PDF pages to {output}")


if __name__ == "__main__":
    main()
```

### 4. 一条命令完成裁切和拆分

在该目录打开 PowerShell，运行下面的命令。把 `1.pdf` 换成实际文件名。

```powershell
python .\crop_split_pdf.py --file ".\1.pdf"
```

脚本会在输入 PDF 旁创建 `1_split` 文件夹，按幻灯片顺序生成 `page-001.pdf`、`page-002.pdf` 等。可以用 `explorer .\1_split` 打开结果目录。若使用绝对路径，把整个路径放在引号里，例如 `--file "D:\演示文稿\研究成果 1.pdf"`。

### 常见情况

| 情况 | 处理方式 |
| --- | --- |
| PowerShell 提示找不到 `py` 或 `pdfcropmargins` | 激活已安装 Python 的 Conda 环境，按步骤 2 和步骤 4 使用 `python`。 |
| 终端出现 `fitz API is deprecated` | 这是依赖的弃用提示。如果随后显示 `Saved … PDF pages to …`，可以打开输出目录查看结果。 |
| 提示 `Output folder already exists` | 先重命名或移走已有输出目录，再重新运行。 |
| 需要紧贴内容边缘 | 把脚本中的 `"-a", "-6"` 从参数列表中移除。`-p 0` 会去掉检测到的白边，`-a -6` 会加回约 2 毫米。[裁切参数说明](https://pypi.org/project/pdfCropMargins/) |
| 截图自带白边，或者幻灯片有满版底色、边框 | 自动裁切依据可见内容。截图内部的白边也可能被裁掉，满版背景则可能让页面边界维持在原尺寸。需要严格按 PPT 内的图片外框裁切时，应使用图片在幻灯片上的位置和大小。 |
